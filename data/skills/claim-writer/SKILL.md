# Instructions

Write a short, firm, polite claim. Name the SLA and quote the promise. List each counted incident with its date,
minutes and status-page link. State the credit percentage and the dollar amount. Ask for it on the next invoice.
Check the playbook for lessons about this vendor before writing, and apply every one.
